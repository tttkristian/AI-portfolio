# 3. Selected Technical Projects

Four projects that show range: classical search, local search, adversarial search under hidden information, and experimental methodology. Each project page follows the same artifact card: **problem → decisions → results & verification → reflection → outcome connection → Gen AI disclosure**.

---

### 🁫 [Team Domino AI](../projects/domino-ai/README.md)
**Ch. 5, Adversarial search · Group B · My role: [[ ]]**
A 2-vs-2 domino agent that samples possible hidden hands (Monte Carlo) and solves each with alpha-beta search. Evaluated in a round-robin tournament, team experiments, ablations and robustness tests.
**Outcomes:** CO2 → SO2 (design), CO1 → SO1 · optional SO5, SO6

### 🧭 [Search: Robot Paths & River Crossings](../projects/pa3-search/README.md)
**Ch. 3, Search · Group B · I wrote all the code and ran the experiments**
Reformulated a continuous robot-navigation problem as a 35-state visibility graph, compared six search algorithms on 60 random scenes, and showed why repeated-state checking is essential.
**Outcomes:** CO1 → SO1, CO4 → SO3

### ⛰️ [Local Search on 8-Puzzle & 8-Queens](../projects/local-search/README.md)
**Ch. 4, Local search · Group B · My role: [[ ]]**
7,208 seeded runs comparing hill climbing, first-choice, random-restart and simulated annealing, validated against the textbook's published figures.
**Outcomes:** CO1 → SO1 · optional SO6

### ⏱️ [Python vs NumPy Performance](../projects/python-performance/README.md)
**Programming Assignment 1 · Group B · My role: [[ ]]**
Measured when NumPy beats pure Python and reproduced two common timing mistakes to show how much they distort the conclusion.
**Outcomes:** optional SO6
